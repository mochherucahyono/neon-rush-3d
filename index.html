TENTANG GAME

Neon Rush 3D — WebGL Endless Runner

Cara Bermain

Bertahanlah sejauh mungkin di lintasan 3 jalur berkecepatan tinggi. Hindari rintangan merah dan kumpulkan koin emas untuk memperbesar skor.

Jenis Rintangan

  • Blok Rendah: Lompati (W / Spasi / Swipe Atas) atau pindah jalur.
  • Palang Tinggi: Menunduk/slide (S / Panah Bawah / Swipe Bawah) atau pindah jalur.
  • Blok Penuh: Wajib pindah jalur (A/D / Panah Kiri-Kanan / Swipe Kiri-Kanan).

Sistem Skor & Info

Skor dihitung dari jarak tempuh ditambah +10 poin per koin. Skor terbaik tersimpan otomatis di browser (localStorage).
